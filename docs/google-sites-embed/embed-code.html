📦 Unduh Ekstensi
Panel samping cerdas SIMRS/EHR (.ZIP)
1
Klik tombol Unduh Ekstensi di atas, lalu Ekstrak (Unzip) file internize-ai-extension.zip ke folder komputer Anda.
2
Buka peramban Chrome / Edge, ketik chrome://extensions di bilah alamat, lalu aktifkan saklar Developer Mode di pojok kanan atas.
3
Klik tombol Load Unpacked (Muat yang belum dibongkar), lalu pilih folder hasil ekstrak tadi. Selesai! Klik ikon internize.ai di toolbar peramban untuk membuka panel klinis.
